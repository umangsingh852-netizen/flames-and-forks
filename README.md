#  Flames & Forks

A full-stack food ordering web application built with Flask and MySQL.

##  Live Demo

[Flames & Forks](https://flames-and-forks.onrender.com)

## Tech Stack

- Python
- Flask
- MySQL
- HTML
- CSS
- Jinja2
- Gunicorn
- Aiven
- Render

## Features

- User registration and login
- Food menu
- Shopping cart
- Order placement
- Payment method selection
- Order history
- Admin dashboard
- Food management
- Order status management
- Responsive UI
